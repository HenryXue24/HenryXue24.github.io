A.1 Photograph Sets

Two overlapping photo sets were captured for alignment: a two-image classroom view and a three-image hillside panorama.

For both sets, the camera's center of projection was kept fixed while the camera was rotated between shots. This makes the views related by projective transformations and preserves overlap for matching scene points.

A.2 Recovering Homographies

The notebook estimates a homography from manually selected point pairs with numpy.linalg.lstsq, fixing H33 = 1. Each pair contributes two linear equations.

For a point (x, y) in image 1 that matches (u, v) in image 2, let h = [h11, h12, h13, h21, h22, h23, h31, h32]T. The correspondence contributes these rows to Ah = b:

[x, y, 1, 0, 0, 0, -ux, -uy] h = u
[0, 0, 0, x, y, 1, -vx, -vy] h = v

The current examples use four point pairs each, giving eight equations for eight unknowns. This is the minimum determined case, not an overdetermined fit; using more than four well-spread correspondences would make the estimate less sensitive to clicking error.

A.3 Image Warping

Inverse warping visits each output-canvas pixel and maps it back into the source image, avoiding the gaps that can occur when forward-mapping source pixels.

Nearest-neighbor interpolation rounds to the closest source pixel. It is simple and fast, but can look blocky along transformed edges. Bilinear interpolation computes a weighted average of the four surrounding pixels, producing smoother results at the cost of additional sampling work and some edge softening.

A.4 Blending the Images into Mosaics

Each view is warped into a shared canvas. Spatial weights favor pixels farther from image boundaries, and the weighted values are normalized by their total weight to combine overlapping regions.

The classroom mosaic separates low- and high-frequency image content before blending the two layers, which helps reduce visible seams while retaining detail. The hillside and street mosaics use a weighted average. The street canvas is shown before blending alongside the final result.
